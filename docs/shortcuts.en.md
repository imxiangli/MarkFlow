# MarkFlow keyboard shortcuts

Shortcuts follow the Sublime Text 4 defaults, with a few changes for Markdown editing. Generated by `npm run docs:shortcuts` from `src/shared/keybindings.ts`; do not edit by hand.

- **Chords**: `⌘K` / `Ctrl+K` is a chord prefix. Press `⌘K`, then the second key when the hint appears (e.g. `⌘K ⌘U` for upper case). Esc or 2.5 seconds without a key cancels.
- **Command palette**: `⇧⌘P` / `Ctrl+Shift+P` runs any command by name and shows its shortcut.
- **Goto Anything** (`⌘P` / `Ctrl+P`): type a file name to open it; `file:line` opens it at a line and `file@heading` at a heading. Start with `:` for a line in the current document, `@` for a heading in it, `#` for headings across the folder and `>` for commands.
- Editing commands act on the focused editor, including the block editor opened by double-clicking in reading mode. Bookmarks, find next and jump back also work in reading mode.
- Differences from Sublime: insert link is `⌥⌘K` (`⌘K` is the chord prefix); on macOS `⌘1–9` switch tabs and headings are `⌃⌘1–6`; reading / editing toggle is `⌥⌘E` (`⌘E` is “use selection for find”); `⌘R` goes to a heading.
